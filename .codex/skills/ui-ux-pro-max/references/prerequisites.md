# Prerequisites

Check whether Python is available before using the search tooling:

```bash
python3 --version || python --version
```

If Python is missing, install it based on the user's platform:

## macOS

```bash
brew install python3
```

## Ubuntu or Debian

```bash
sudo apt update && sudo apt install python3
```

## Windows

```powershell
winget install Python.Python.3.12
```

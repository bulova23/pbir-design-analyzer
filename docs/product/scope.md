# v1.0 Supported Product Scope

Status: frozen for readiness review at commit `a67af7ad88bf2e7d6fd4bc162be84731d5ae1390`.

## Core

**Discover → Score → Understand Evidence → Prioritize → Preview → Fix/Rollback → Deliver**

- PBIR discovery and deterministic scoring.
- Normalized findings, evidence, readiness, prioritization, and fix-plan presentation.
- Supported deterministic mutation preview, apply, and rollback on disposable/local report copies.
- Downstream review/export deliverables already exposed by the score-panel workflow.

## Optional

- Rendered Review evidence and bounded screenshot attachments.
- Fabric App Review Mode and semantic-model usage evidence as advisory analyzer evidence.
- Workspace personas, reviewer-comment personas, and presentation-only cross-page matrix navigation.

## Experimental

- Dormant provider/runtime, sandbox, certification, remote-worker, and generation architecture not registered in the shipped analyzer composition root.
- Advisory AI proposal enrichment; it has no mutation authority.

## Deferred

- Advanced screenshot or Visual Intelligence analysis.
- Broad report generation and deployment functionality.
- Enterprise governance expansion.
- Provider execution and hosted/runtime integration.

## Unsupported

- Autonomous Fabric App execution or deployed-app inspection.
- Screenshot interpretation as deterministic scoring.
- AI-controlled report mutation.
- Marketplace or GitHub release publication from this readiness review.

Fabric App Review remains advisory and does not become PBIR scoring or deterministic mutation authority.
